Sum up 23 November's world news in one image: 16 stories from Monday 23 November 2026 — the COP31 backlash in Canberra, Wall Street's rebound as Nvidia reinstated Jensen Huang, Ukraine sinking the Russian corvette Merkury off Libya — laid out as a maximal-density broadsheet with a pin map, a stat strip, an ALSO list and a DATE CHECK box that keeps earlier-date news out. Every story names its source, and every story's event date was checked against two sources before it was printed.

## Run it

```sh
node main.ts
```

The program copies the finished poster (`entry.png`, a 1024×1024 JPEG, 321,747 bytes) to `entry.png` inside the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output` by default). It writes the same bytes on every run.
